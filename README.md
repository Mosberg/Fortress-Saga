# Fortress-Saga
Create a complete repository for a Fortress Saga GitHub.io page for me with all information, wikis, updates, guides, calculators, planners, spreadsheets, wandering merchants, tools, helps, tips, descriptions and everything else that can be useful for a Fortress Saga Player https://share.gemini.google/7eL8PCnZpGYQ

## Site

The GitHub Pages site is `index.html` at the repo root, with game data in `data/` and the JSON schema in `schemas/`. These were generated by the `build_repo.py` script in `drafts/6.md`. The `drafts/` folder holds the original AI chat answers the site was built from; the numbers and formulas in them are unverified.
